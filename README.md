# مدير المهام المتقدم (Advanced Task Manager)

تطبيق متكامل لإدارة المهام اليومية مبني بلغة Dart وإطار عمل Flutter، مصمم ليعمل بشكل محلي بالكامل (Offline-first) مع واجهة عربية أنيقة تدعم الاتجاه من اليمين إلى اليسار (RTL).

## نظرة عامة
جاءت فكرة هذا التطبيق لتوفير أداة سريعة وخفيفة لتنظيم المهام، بعيدًا عن التطبيقات المعقدة التي تتطلب اتصالاً دائمًا بالإنترنت. يعتمد التطبيق على قاعدة بيانات محلية (SQLite) لضمان حفظ بيانات المستخدم بأمان على جهازه فقط، مما يجعله أداة مثالية للاستخدام الشخصي اليومي.

## الميزات الرئيسية
* **نظام حسابات آمن:** تسجيل مستخدمين جدد مع تشفير كلمات المرور باستخدام خوارزمية (SHA-256) مع ملح عشوائي (Salt) قبل حفظها في قاعدة البيانات.
* **إدارة المهام:** إضافة، تعديل، وحذف المهام بسهولة. مع دعم السحب للحذف (Swipe to dismiss) وتأكيد قبل التنفيذ لمنع الحذف العرضي.
* **تصنيف وأولويات:** إمكانية تصنيف المهام (عام، عمل، شخصي، إلخ) وتحديد أولوية لكل مهمة (من 1 إلى 5).
* **لوحة تحكم (Dashboard):** إحصائيات سريعة في أعلى الشاشة تعرض إجمالي المهام، المهام المكتملة، والمهام قيد التنفيذ.
* **تنظيم متقدم:** فصل المهام المكتملة في شاشة خاصة، لتبقى الشاشة الرئيسية مخصصة للمهام التي تحتاج إلى إنجاز.
* **بحث وفلترة:** البحث الفوري عن المهام بالاسم، مع إمكانية الترتيب حسب الأحدث، الأقدم، الأولوية، أو أقرب موعد استحقاق.
* **تخصيص المظهر:** دعم كامل للوضع الليلي والنهاري (Dark/Light Mode) مع حفظ التفضيل تلقائيًا.
* **إدارة الحساب:** إمكانية تغيير كلمة المرور من داخل التطبيق، وتسجيل الخروج بأمان.

## التقنيات والمكتبات المستخدمة
* **Flutter & Dart:** لبناء واجهة المستخدم والمنطق البرمجي.
* **SQLite (sqflite):** لتخزين بيانات المستخدمين والمهام محليًا.
* **SharedPreferences:** لحفظ جلسة تسجيل الدخول وتفضيلات المظهر.
* **Crypto:** لتشفير كلمات المرور وحماية بيانات المستخدمين.
* **Intl:** لتنسيق التواريخ والأوقات وفقًا للغة العربية.
* **Flutter Localizations:** لدعم اللغة العربية والاتجاه RTL بشكل رسمي.
